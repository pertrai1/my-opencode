name: research
description: Use when the user requests durable, cited research or explicitly asks to delegate research.
---

Use available delegation only when it improves the work. Otherwise research directly.

Its job:

1. Investigate the question against **primary sources** — official docs, source code, specs, first-party APIs — not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Cite each material claim.
3. Write a Markdown file only when the user requests a durable research artifact or the repository convention requires one; otherwise report the findings in the response.
